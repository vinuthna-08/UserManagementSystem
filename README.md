# User Management System

## ICT711 Assessment 4 - Enhanced User Management System using Java GUI (JavaFX), Text-Based Interface, Bubble Sort, Linear Search and File Handling

### Student: Sri Sai Vinuthna Pinninti | ID: 20037843

## Project Overview
A Java-based User Management System with dual interfaces:
- Graphical User Interface (GUI) built with JavaFX
- Text-Based Interface (TBI) using Console

## Features
- Add, View, Update, Delete users (CRUD)
- Search users by name (Linear Search)
- Sort users by Name A-Z (Bubble Sort)
- Sort users by ID (Bubble Sort)
- File handling - data saved to users.txt
- Input validation and exception handling
- JUnit 5 automated testing

## Technologies Used
- Java 17
- JavaFX 17
- JUnit 5
- Eclipse IDE

## Files
- User.java - Abstract base class
- AdminUser.java - Admin subclass
- RegularUser.java - Regular user subclass
- UserManager.java - Core logic, sorting, searching
- FileHandler.java - File save/load
- Main.java - Text-Based Interface
- UserManagementGUI.java - JavaFX GUI
- UserManagerTest.java - JUnit tests
